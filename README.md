# Pokemon Shiny Guide

Hello! This repository is for a website that I worked on during October of 2022, and have been maintaining since then as each new Pokemon game comes out.
This tool lets you select which games you own, which shiny charms you have, and will tell you the fastest way to shiny hunt that Pokemon, or even the whole Dex.
You can also use it to track all of your shinies, including the amount and what games they are in.
If you notice any issues, discrepancies, or have any suggestions, please feel free to reach out.
Hopefully you find some use from this website!
